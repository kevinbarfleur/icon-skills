# Optional integrations

The standalone SVG workflow in SKILL.md is complete without these integrations.
Use an integration only when it exists in the user's environment and benefits the requested outcome.

## Existing collection MCP

If the Icons MCP is already connected, `search_collection` can find examples by product situation and `inspect_identity` can read their intentions and sources.
`render_identity` previews or recolors an existing vector, while `export_identity` exports the existing expressions.
`create_artwork` validates a new SVG, returns review proofs and saves an independent revision after review.
These are tools for file and render operations, not an autonomous artistic director.
Do not attempt to install a missing MCP merely to satisfy this reference.
The earlier parametric library uses separate `describe_subject`, `render_icon`, `create_subject` and `export_icon` tools.

## Blender and motion

Blender is needed only when editing or creating an actual 3D scene.
A shallow relief does not imply a complete model from every angle.
An SVG recolor does not update an existing Blender scene or its render.

Motion remains a separate future workflow.
Preserve the approved mark when exploring motion, and do not simplify a static icon merely because it would be easier to animate.
This skill does not claim to include a validated portable animation engine.
